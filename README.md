# ClipFlow
ClipFlow es un gestor de portapapeles ligero y multiplataforma que vive en la barra de menú/bandeja del sistema.
Guarda todo lo que copias (texto, código, imágenes, colores) y te permite recuperarlo al instante con un atajo global.  Killer features: 
    🎨 Extractor de colores — Detecta HEX/RGB/HSL y los muestra con preview 
    👁️ OCR local — Extrae texto de imágenes usando las APIs nativas del SO 
    🧹 Pegado como texto plano — Sin estilos feos de webs 
    ⚡ Transformadores rápidos — MAYÚSCULAS, snake_case, JSON pretty, slug 
    🔒 Modo privado — Excluye gestores de contraseñas automáticamente 
Stack: Tauri 2 (Rust) + Svelte 5 + SQLite. Binario <15MB, RAM <40MB
